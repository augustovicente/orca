# Tax Filing

Checklist:

- Collect sales/purchase ledgers for the period.
- Compute tax base and liability.
- Compare to prior period for anomalies.
- Generate submission file in the required format (XML/CSV).
- Archive evidence (reports + calculations) in `out/tax-<period>/`.

Always double-check totals and keep an audit trail.
